How I Build

A visual process for turning fuzzy product ideas into working physical-digital prototypes.

01

Frame

Define the problem, user need, constraints, and the smallest useful product direction.

02

Map

Sketch flows, system architecture, materials, electronics, data, and interaction states.

03

Prototype

Build fast with Figma, code, CAD, 3D printing, microcontrollers, and tested components.

04

Test

Look for failure points in usability, enclosure fit, performance, assembly, and behavior.

05

Tell

Turn the build into a clear case study with decisions, tradeoffs, visuals, and outcomes.
